How-to guides

Step-by-step instructions for the everyday jobs at your land trust.

Add a property

Portfolio › Properties

  1. Select + New.
  2. Fill in Street address, Unit (if any), City, State, County and ZIP code. Pick the State first: the County list only shows that state's counties.
  3. Pick the Neighborhood if the home belongs to one (for example Maple Court). Homes and shared parcels in the same neighborhood sort together in the view Properties by neighborhood.
  4. Add the Parcel number and the details you have (type, bedrooms, year built).
  5. Under Program, set the Status (for example Vacant or Owner-occupied) and the Tenure type.
  6. Select Save. The property gets its record number (P-00001) and its name, which is the address. You don't need to type the name.
  7. Wait a few seconds while the form says it's setting up the document folder. The form reopens by itself when the folder is ready (named like 412 Fir St - P-00004).
  8. Open the Documents tab to upload the deed, photos or inspections. The Documents folder link opens the same folder in SharePoint.

A new neighborhood is added under Settings › Lists: select + New, set List to Neighborhood and type its name. Land that isn't housing uses the property types Commercial, Agricultural, Land only or Common area. A common area has no status, so the Overview doesn't count it as a home.

Set up a household

People › Households

  1. Select + New, add the Primary email and phone, and set the Status (Applicant, Homeowner and so on).
  2. Select Save. Leave the name blank: it fills in from the primary applicant.
  3. Open the Members tab and select + New household member.
  4. Enter First name and Last name, and set Applicant role to Primary applicant. Save and close.
  5. Add everyone else in the household the same way, with a Relationship to primary applicant. Tick On title for anyone who will be on the deed.

The household is named after the primary applicant's last name, for example Rivera. If another household already has that name, the first name is added: Rivera, Maria.

Move a household into a home

Portfolio › Occupancies (or the property's Occupancies and sales tab)

An occupancy links a household to a property for the time they live there. It holds the resale formula, insurance and annual verifications.

  1. Select + New. Pick the Property and the Household. The name fills in, for example Rivera - 123 Main St.
  2. Set Role (Owner or Tenant), Status = Current, and the Start date.
  3. Add the Lease or covenant recording number.
  4. On the Resale price tab, choose the Resale formula and fill in Base price, Base date and Annual rate (%) (the appraisal share terms appear when you choose an appraisal based formula).
  5. Improvement credits: on the same tab, add each approved improvement with + New Improvement credit: its Original value, the date that value is from, and a Depreciation period (years) if it loses value over time. Current value is worked out for you, and the total is added to the maximum resale price.
  6. Follow-ups: on the Stewardship tab, add something to come back to with + New Follow-up and a Due date. Set its Status to Done when it is. The Stewardship Dashboard counts the ones that are due.
  7. Save. Wait a few seconds while the form sets up the occupancy's document folder (named like Rivera - 123 Main St - O-00004), then upload the ground lease and closing papers on the Documents tab.
  8. On the property, set Current occupancy to this occupancy and its Status to Owner-occupied.

Insurance policy: enter Carrier, Policy number, Renewal date, Dwelling coverage (A), Extended dwelling (%) and Replacement cost. Tick CLT listed as additional insured once you've seen it on the declarations page, and set Verified date.

Later, a sale's closing will update the property's current occupancy and status automatically. For now, do the last step by hand.

Run occupancy verifications

Activities › Occupancy verification

  1. Choose who to ask. Set the Year being verified and the Due date. Households with no request for the year are ticked. For each, choose Online form or Paper.
  2. The email (online form only). Check the form link and the wording. Words in curly brackets are filled in for each household, and each household gets its own link. A plain form link gets the year, the household ID and a code added. A link written with the form's own question names can also open the form with the owner's name and the home's address already filled in: the page lists the words to use, and the link is kept in your organization's settings.
  3. Send. The page shows one finished email at a time. Copy it into your mail program or select Open in mail, send it, then select Sent. Stu does not send email itself.
  4. Paper copies are opened as soon as you start. Print and hand out your form.
  5. Review each request when it comes back: under Requests, select Open, enter the date and what you found, choose Approved or Issue found, and Save. To keep the signed paper form, choose it under Add the signed form (a PDF or a photo) before you save.
  6. Issue found needs a note saying what the issue is. The request stays open as Issue found, and the household isn't asked again, until you open it again and approve it (or cancel it).
  7. An online request that came back on paper: open it, set Came back as to Paper, add the signed form and save.
  8. Go back into a request: tick Show closed and cancelled ones too and select Open. This works for approved ones too. You see the link that was sent (with Copy and Open the form), and can view, add or replace the signed form.
  9. Cancel a verification, open or closed, with Cancel this verification. It stays on record as Cancelled and the household can be asked again.
Only an approval sets the occupancy's Last occupancy verification date, so the home drops off the overdue list on the Verification hub. A form that has come in, or an issue, doesn't move it. Cancelling an approved one takes that date back to the verification before it, so the home shows as overdue again if that was more than the usual time ago.
When a household sends in the online form, its request turns to Received by itself (and says To review on the Verification hub). Open it to read what they answered, then save your review. A household that asks for contact about its mortgage gets a Homeowner request called Mortgage help requested. The form is about occupancy only: insurance is checked on its own, under Run insurance verifications.

Coming later: Stu sending the emails itself.

Run insurance verifications

Activities › Insurance verification

When the insurer's card arrives. If your organization is listed as additional insured, the insurer mails you a card. Entering it is that home's insurance verification, and nobody has to ask the household.

  1. Select Enter an insurance card at the top of the page.
  2. Choose the Home, and enter the Date on the card.
  3. Enter the Replacement coverage limit if the card shows it, add a photo or scan of the card, and put the insurer, policy number and anything else worth keeping under Notes.
  4. Select Save the card. It is saved as an approved insurance verification, with Insurer's card under How. If the home had a request open, the card closes it.

When no card comes, ask the household for proof. Stu keeps track of who you asked; it doesn't send anything.

  1. Choose who to ask. Homes with no insurance verification in the last year are ticked. Set the Due date and select Start requests.
  2. Ask each household the way you usually do: an email, a call, a letter.
  3. What is waiting, under Requests: Requested means the household has been asked and you are waiting for its proof.
  4. Open one when the proof comes in, and add the document (a PDF or a photo). Select View to look at one that is already there.
  5. Review it: enter the date, the Replacement coverage limit from the proof, choose Approved or Issue found, add notes, and Save. An issue needs a note saying what it is, and the request stays open as Issue found until you open it again and approve it.
  6. Cancel one, open or closed, with Cancel this verification.
Only an approval sets the occupancy's Last insurance verification date. On the Verification hub, a home with one open shows it in the Insurance list: select it to open that verification.

Use the Verification hub

Start here › Verification hub

The page has two parts that run on separate clocks: Occupancy verification and Insurance.

  1. Occupancy verification lists every current occupancy with the date of purchase and Overdue, Due soon or Up to date. It falls due each year on the anniversary of the purchase, whenever the last one came back. A new owner isn't due until the first anniversary.
  2. To send the occupancy verification form, tick the households you want (every one that is overdue or due soon and hasn't been asked starts ticked) and select Start occupancy verifications above the list, or Ask this household on one row. Both open Occupancy verification with those households ticked.
  3. Once a request is under way, the row says In progress, To review or Issue found. Select it to open that request.
  4. Insurance lists the homes with no insurance verification entered in the last 12 months. A new owner's first one is due a year after the purchase, the same day as the first occupancy verification.
  5. When the insurer's card arrives in the mail, select Enter the card on the home's row, or Enter an insurance card above the list. See Run insurance verifications. Saving the card takes the home off the list.
  6. If no card has come, select Ask for proof on the row. It opens Insurance verification with that household ticked.
  7. Click the home's name to open its occupancy. The Stewardship tab has the dates, follow-ups, relationship notes and verifications for that household in that home.
Last contact is the newest relationship note, or verification that came back. Add a relationship note on the occupancy's Stewardship tab every time you are in touch with a household, even briefly.

An occupancy verification counts for an anniversary when it came back no more than 60 days before it, or any time after. Insurance is every 12 months unless your organization's settings say otherwise.

Do staff walk-bys from your phone

Start here › Stu in the wild

Stu in the wild is the page for work away from your desk, built for a phone. Open Stu in the Power Apps app on your phone (or in the phone's browser): on a phone it opens on this page. From anywhere else, select Stu in the wild in the menu.

  1. Tap Staff walk-by, then the neighborhood you are in.
  2. Every home has a card, empty homes too. Red is to do, amber is saved and not submitted, green is done. Tap a home.
  3. Type your Notes.
  4. If something needs coming back to, tick Needs a follow-up. The due date starts as today; change it if you like.
  5. Tap Take a photo for each photo, or Choose photos to add ones already on the phone. Tap the × on a photo to take it off.
  6. Tap Save to keep it and go back to the neighborhood. The home turns amber, and you can open it again to add more.
  7. Tap Submit when the home is finished. It turns green, and a ticked follow-up is added to Stu as an open follow-up, which counts on the Stewardship Dashboard.
A walk-by is kept on the property, so the home's history carries on through every owner and every gap between owners. When someone lives there, the walk-by and its follow-up also show on that occupancy. At your desk, open the property's Stewardship tab: Walk-by history shows every walk-by for the home, newest first, with its notes and photos. Select a photo to see it larger. Opening one walk-by shows its photos on its own form too.

A green home goes back to red 12 months after its last submitted walk-by, unless your organization's settings say otherwise. The page needs a signal: if a save fails, what you typed and the photos stay on the screen so you can try again.

Handle a homeowner request

Stewardship › Homeowner requests › view Open requests

Use a request for anything a homeowner needs the land trust's OK for: a capital improvement, an ERRR repair draw, a refinance, renting or subletting, a leave of absence, or an intent to sell.

  1. Select + New. Pick the Occupancy and Property, the Request type and the Request date, and describe it under Details.
  2. While you look into it, set Status = Under review.
  3. Record the decision: Status (Approved, Approved with conditions or Denied), Decision date and any Conditions.
  4. For a capital improvement, enter the Approved resale credit. For a repair paid from the reserve, enter the Approved ERRR draw, then add the payment on the ERRR draws tab.
  5. When the work is done, set Status = Completed and the Completed date.

Run a resale

Activities › Resale

The Resale page walks a resale through five steps. Each step saves as you go, so you can leave and come back; pick the resale at the top of the page.

  1. Start the resale: select Start a resale, choose the home, and enter the date the homeowner gave notice.
  2. Price and what the seller owes: the Formula price and Added value (capital improvements) come from the occupancy and add up to the Maximum resale price. Loans from your organization are worked out for today; change the total to the real payoff. Add any Other credits and Other debits, saying what each is for. The page shows what the seller is left with.
  3. Find the buyer: pick a household that is already certified, or select Start a project for this home to run an application round, and come back to pick the buyer it produces.
  4. Contract: enter the Purchase price, the date the purchase and sale agreement was signed, lender and title company. Under How the purchase price is made up, add a line for each part: the buyer's cash, each loan (with its interest rate), each subsidy. The lines should add up to the purchase price. The home is marked Sale pending. If the price is above the maximum resale price, the seller's side stops at the maximum and the difference is recorded as Subsidy recaptured by your organization.
  5. Closing: once the sale has closed, enter the Closing date, the buyer's Closing costs and add the Final settlement statement if you have them, then select Record the closing. The statement can also be added, replaced and viewed on this page after the closing. This ends the seller's occupancy, starts the buyer's with the same resale formula from the new price and date, and updates the home and both households.
To record a loan your organization made to a homeowner, open their occupancy, go to the Resale price tab and add it under Loans from the organization. The regular payment is filled in from the balance, rate and dates, and you can change it.

After closing, open the new occupancy and check its terms if the buyer's lease differs from the seller's.

Finish up after a sale

Activities › After the sale

The work that follows a closing, for a resale or a first sale. Recording a closing on the Resale page brings you straight here.

  1. Choose the Sale. Sales with work left are listed first. The first time a sale is opened it gets its own copy of your organization's task list.
  2. Enter the buyer's insurance: select Enter the insurance, fill in the insurer, policy number, dwelling coverage and dates, tick the box if your organization is listed as additional insured, add the proof if you have it, and select Save the insurance. This creates the home's insurance policy and its first insurance verification, dated the closing, so the next one falls due a year after the purchase.
  3. Add the final settlement statement: choose the file and select Save the file.
  4. For the other tasks, use the button to open the place the work is done, then select Mark done.
  5. If a task doesn't apply to this sale, select Not needed. Undo puts a task back on the list.
The Stewardship Dashboard shows Sales with set-up to finish: closed sales that still have tasks to do.

The list is your organization's own. To change it, go to Settings › After-sale tasks: add a task, reword one, change the order, or deactivate one you don't use. Which sales decides whether a task is for every sale, resales only or first sales only. A change affects sales opened here afterwards, not ones already under way.

Record a first sale

Portfolio › Sales

For a home being sold for the first time. For a resale, use Run a resale.

  1. 1. Property: pick the Property and Sale type.
  2. 2. Buyer and contract: pick the Buyer household and enter the Purchase and sale agreement signed date, Purchase price, lender and title company. Status stays Pending.
  3. 3. Closing: on closing day, enter the Closing date and set Status = Closed.
  4. Then create the buyer's occupancy (see Move a household into a home), and pick it as the sale's Buyer's occupancy.

Find and add documents

The Documents tab on a property, occupancy or household

  1. Open the property, occupancy or household and select the Documents tab.
  2. Select Upload and pick the file. It's saved in SharePoint, in that record's own folder.
  3. To work in SharePoint directly, select Open location. You'll go straight to the folder.

What goes where:

  • Property: what stays with the home whoever lives there. Deeds, surveys, inspections, permits and photos.
  • Occupancy: what belongs to one household's time in that home. The ground lease and its memorandum, closing papers, insurance, and repair reserve (ERRR) requests. A resale starts a new occupancy with its own empty folder.
  • Household: application and certification documents only. Household documents are restricted to staff.

Applicants' uploads stay in the online forms until the household is certified. Never store Social Security numbers or bank account numbers in the app.

Add a dropdown choice

Settings › Lists

Many dropdowns (State, County, Property type, Tenure type, Relationship, Income type and others) come from Lists, which staff can add to.

  1. Select + New.
  2. Pick which List it belongs to (for example Property type), and type the value as its name.
  3. Optionally set a Sort order to control where it appears in the dropdown.
  4. If online forms send this value with different wording, add each wording on its own line under Form answers.
  5. Save. It shows up in the dropdown right away.

Statuses and stages (for example Property status or Request status) are fixed, because automations depend on them. To change one, ask your system administrator.
