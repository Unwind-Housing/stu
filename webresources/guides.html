How-to guides

Step-by-step instructions for the everyday jobs at your land trust.

Add a property

Portfolio › Properties

  1. Select + New.
  2. Fill in Street address, Unit (if any), City, State, County and ZIP code. Pick the State first: the County list only shows that state's counties.
  3. Pick the Neighborhood if the home belongs to one (for example Maple Court). Homes and shared parcels in the same neighborhood sort together in the view Properties by neighborhood.
  4. Add the Parcel number and the details you have (type, bedrooms, year built).
  5. Under Program, set the Status (for example Vacant or Owner-occupied) and the Tenure type.
  6. Select Save. The property gets its record number (P-00001) and its name, which is the address. You don't need to type the name.
  7. Wait a few seconds while the form says it's setting up the document folder. The form reopens by itself when the folder is ready (named like 412 Fir St - P-00004).
  8. Open the Documents tab to upload the deed, photos or inspections. The Documents folder link opens the same folder in SharePoint.

A new neighborhood is added under Settings › Lists: select + New, set List to Neighborhood and type its name. Land that isn't housing uses the property types Commercial, Agricultural, Land only or Common area. A common area has no status, so the Overview doesn't count it as a home.

Set up a household

People › Households

  1. Select + New, add the Primary email and phone, and set the Status (Applicant, Homeowner and so on).
  2. Select Save. Leave the name blank: it fills in from the primary applicant.
  3. Open the Members tab and select + New household member.
  4. Enter First name and Last name, and set Applicant role to Primary applicant. Save and close.
  5. Add everyone else in the household the same way, with a Relationship to primary applicant. Tick On title for anyone who will be on the deed.

The household is named after the primary applicant's last name, for example Rivera. If another household already has that name, the first name is added: Rivera, Maria.

Move a household into a home

Portfolio › Occupancies (or the property's Occupancies and sales tab)

An occupancy links a household to a property for the time they live there. It holds the resale formula, insurance and annual verifications.

  1. Select + New. Pick the Property and the Household. The name fills in, for example Rivera - 123 Main St.
  2. Set Role (Owner or Tenant), Status = Current, and the Start date.
  3. Add the Lease or covenant recording number.
  4. On the Resale price tab, choose the Resale formula and fill in Base price, Base date and Annual rate (%) (or the appraisal share terms).
  5. Save. Wait a few seconds while the form sets up the occupancy's document folder (named like Rivera - 123 Main St - O-00004), then upload the ground lease and closing papers on the Documents tab.
  6. On the Stewardship tab, add the household's Insurance policy (see below).
  7. On the property, set Current occupancy to this occupancy and its Status to Owner-occupied.

Insurance policy: enter Carrier, Policy number, Renewal date, Dwelling coverage (A), Extended dwelling (%) and Replacement cost. Tick CLT listed as additional insured once you've seen it on the declarations page, and set Verified date.

Later, a sale's closing will update the property's current occupancy and status automatically. For now, do the last step by hand.

Run annual verifications

Stewardship › Annual verifications › view Verifications to do

  1. For each current occupancy, add a verification: + New, pick the Occupancy, and set the Year and Due date. Status starts at Due.
  2. When you send the form to the homeowner, set Status = Sent and the Sent date.
  3. When it comes back, set Status = Received and the Received date, then fill in the findings: Primary residence confirmed, Rental status and Insurance declarations received.
  4. Finish with Approved, or Issue found (add a note saying what's wrong and follow up). Use Waived if this year's check doesn't apply.

Coming later: verifications created automatically 60 days before each anniversary, and online replies matched by their verification code.

Handle a homeowner request

Stewardship › Homeowner requests › view Open requests

Use a request for anything a homeowner needs the land trust's OK for: a capital improvement, an ERRR repair draw, a refinance, renting or subletting, a leave of absence, or an intent to sell.

  1. Select + New. Pick the Occupancy and Property, the Request type and the Request date, and describe it under Details.
  2. While you look into it, set Status = Under review.
  3. Record the decision: Status (Approved, Approved with conditions or Denied), Decision date and any Conditions.
  4. For a capital improvement, enter the Approved resale credit. For a repair paid from the reserve, enter the Approved ERRR draw, then add the payment on the ERRR draws tab.
  5. When the work is done, set Status = Completed and the Completed date.

Record a sale or resale

Portfolio › Sales

The sale form follows the deal in three steps, top to bottom.

  1. 1. Property: pick the Property and Sale type. For a resale, pick the Seller's occupancy and record the Maximum resale price at sale from that occupancy's Resale price tab.
  2. 2. Buyer and contract: pick the Buyer household and enter the Contract date, Purchase price, lender and title company. Status stays Pending.
  3. 3. Closing: on closing day, enter the Closing date and set Status = Closed.
  4. Then update the occupancies: set the seller's occupancy to Past with an End date, create the buyer's occupancy (see Move a household into a home), and pick it as the sale's Buyer's occupancy.

Coming later: closing a sale will update occupancies, the property and statuses automatically.

Find and add documents

The Documents tab on a property, occupancy or household

  1. Open the property, occupancy or household and select the Documents tab.
  2. Select Upload and pick the file. It's saved in SharePoint, in that record's own folder.
  3. To work in SharePoint directly, select Open location. You'll go straight to the folder.

What goes where:

  • Property: what stays with the home whoever lives there. Deeds, surveys, inspections, permits and photos.
  • Occupancy: what belongs to one household's time in that home. The ground lease and its memorandum, closing papers, insurance, and repair reserve (ERRR) requests. A resale starts a new occupancy with its own empty folder.
  • Household: application and certification documents only. Household documents are restricted to staff.

Applicants' uploads stay in the online forms until the household is certified. Never store Social Security numbers or bank account numbers in the app.

Add a dropdown choice

Settings › Lists

Many dropdowns (State, County, Property type, Tenure type, Relationship, Income type and others) come from Lists, which staff can add to.

  1. Select + New.
  2. Pick which List it belongs to (for example Property type), and type the value as its name.
  3. Optionally set a Sort order to control where it appears in the dropdown.
  4. If online forms send this value with different wording, add each wording on its own line under Form answers.
  5. Save. It shows up in the dropdown right away.

Statuses and stages (for example Property status or Request status) are fixed, because automations depend on them. To change one, ask your system administrator.
